Spatial & Temporal Locality in CNNs

Spatial Locality: Adjacent pixels in a face crop (112×112) are loaded into cache lines (64 bytes) consecutively. When a 3×3 convolution kernel processes pixel $(x, y)$, subsequent pixels $(x+1, y)$ are already present in L1 cache.

Temporal Locality: CNN weights (e.g., 512 filters of size $3 \times 3 \times 64$) are applied repeatedly across the entire spatial feature map. Caching the filter weights prevents continuous DRAM memory stalls.

The Memory Wall & Cache Miss Penalties

When the working set exceeds L3 cache capacity (e.g. large batch sizes with tens of millions of intermediate activation tensors), the processor experiences cache misses, forcing 60-90ns roundtrips to system DRAM.

GPUs utilize massive multithreading to hide this latency: while Thread 0 waits for DRAM memory fetch, the EU thread scheduler instantly swaps in Thread 1 to execute compute instructions without wasting ALU clock cycles.
